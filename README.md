# Solar Cell Efficiency Prediction Using Machine Learning

## About the Project
This project analyzes perovskite solar cell data using machine learning techniques. It focuses on understanding solar cell performance, predicting efficiency where suitable target data is available, and identifying unusual data patterns.

## Features
- Data preprocessing and cleaning
- Exploratory data analysis and visualization
- Regression model development and evaluation
- Anomaly detection using machine learning
- Feature importance analysis
- Model interpretation using SHAP

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- SHAP
- Google Colab / Jupyter Notebook

## Project Workflow
1. Load and explore the dataset.
2. Clean and preprocess the data.
3. Analyze important features.
4. Train and evaluate regression models.
5. Detect anomalies using different algorithms.
6. Interpret model results using SHAP.

## Dataset
The project uses perovskite solar cell data. The available dataset columns determine which performance values can be analyzed or predicted.

## How to Run
1. Clone or download this repository.
2. Open the Jupyter Notebook in Google Colab or locally.
3. Install the required Python libraries.
4. Upload the dataset or update its file path.
5. Run the notebook cells in order.

## Project Objective
The objective is to apply machine learning to solar cell data to understand performance-related factors and identify unusual observations.
